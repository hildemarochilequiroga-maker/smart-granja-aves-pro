# Landing de ventas - SmartGranjaAves Pro

Esta carpeta es una web comercial independiente del proyecto Flutter.

## Archivos

- `index.html`: estructura y copy orientado a conversion.
- `styles.css`: diseno responsive (desktop y mobile) y estilo visual.
- `script.js`: menu movil y animaciones de revelado.

## Personalizaciones obligatorias

Reemplaza estos enlaces en `index.html`:

- `https://tupago.com/smartgranja`
- `https://tupago.com/smartgranja-pro`
- `https://wa.me/0000000000`
- `ventas@smartgranjaavespro.com`

## Como abrir localmente

Haz doble clic sobre `index.html` o sirvela con cualquier hosting estatico.

## Publicacion recomendada

Puedes subir esta carpeta a Netlify, Vercel o Firebase Hosting como sitio estatico.
